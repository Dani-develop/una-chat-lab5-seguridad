# Medios de prueba

- `prueba.png`: imagen creada para este laboratorio (640 x 360 píxeles).
- `flower.webm`: video de demostración CC0 distribuido por MDN Web Docs:
  https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.webm

Ambos archivos se sirven desde el mismo backend real. Las pruebas E2E no simulan
respuestas de red y no necesitan servicios externos para cargar los medios.
